# Backlog

Open read-side product and process ideas for Mimir Lite. An entry here does not imply approval, implementation, or priority beyond the state shown. Before proposing work on an entry, check it against the current references and the [discarded ideas](discarded.md); an entry is not authorization.

Second slice done: attribute names in WorkWithForWeb filter conditions (extractor 14). Third slice done: `code_references_attribute` from the code Parts of Procedure (Source, Rules), WebPanel and Transaction (Rules, Events), and DataProvider (Source, Rules) (extractor 15): reads, and the write role for unambiguous assignment targets (inside `new`/`for each` blocks, Transaction assignment rules, Transaction-output DataProvider items). Reverse-relation coverage for an `Attribute` target lists those types as partly extracted (`partially_extracted_source_types`, with `extracted` and `missing`), or as unextracted on an index older than the extractor that read them, and the other consumer types as unextracted. Next: a public-export comparison of extractor 16 and 17.
